# Chrome Web Store listing — 0.6.0

## Name

ZBS Eye Browser Bridge

## Summary

Add visible text from your active Chromium tab to your local ZBS Eye timeline.

## Description

ZBS Eye Browser Bridge helps the native ZBS Eye app index useful rendered web text that macOS Accessibility
cannot reliably expose.

- Off by default and enabled only by you.
- Active tab in the focused browser window only.
- Extracts only after authenticating the local Eye app and confirming recording is active.
- Sends visible rendered text, page title, and URL only to loopback on this Mac.
- Excludes passwords, form values, hidden content, scripts, styles, and background tabs.
- No account, analytics, advertising, telemetry, cloud endpoint, or remote code.

Requires ZBS Eye 0.6.0 or later for macOS 15+. Supports Chrome, Dia, Arc, Edge, Brave, Vivaldi, Chromium, and
other compatible Chromium browsers on Mac. Safari is not supported in this release.

## Privacy disclosures

- Personally identifiable information: URL and page title may contain user-provided or identifying data.
- Web history: active-page URL and title.
- Website content: visible rendered text from the active page.
- Authentication information: local write-only ZBS Eye token stored in extension local storage.
- Remote code: no.
- Data sale or transfer: no.
- Primary purpose: local personal activity history inside ZBS Eye.
